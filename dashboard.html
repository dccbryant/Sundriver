  1. Open console.cloud.google.com → APIs & Services → Enabled APIs & services → enable the Google Sheets API.
  2. APIs & Services → Credentials → Create credentials → OAuth client ID → type Web application.
  3. Under Authorised JavaScript origins add the URL this page is served from. Right now that's:
