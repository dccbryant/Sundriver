Sundriver — US Weather & UV Dashboard

Hourly snapshot per US state, sourced from NOAA (api.weather.gov) and EPA (data.epa.gov). Auto-refreshes every hour.

Some browsers block API calls from files opened with file://. If readings stay empty, either open this file in Firefox, or serve it with python3 -m http.server in this folder and visit http://localhost:8000.
Data: National Weather Service forecast hourly + EPA Envirofacts UV hourly forecast. Cached lookups stored in localStorage. Save Excel opens a file picker on your Desktop by default (Chrome/Edge); other browsers save to the Downloads folder.
